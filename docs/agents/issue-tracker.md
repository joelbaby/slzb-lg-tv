# Issue tracker

Use GitHub Issues in joelbaby/slzb-lg-tv for specs and implementation work. Use the authenticated gh CLI. Supply multiline issue and pull-request text with --body-file.

Use native blocking relationships where available, with an explicit Blocked by section in each ticket. PRs as a request surface: no.

Implementation branches target main. Record the base commit and link the originating issue before review. Publishing code here does not authorize an upstream SMLIGHT contribution or changes to device firmware.
