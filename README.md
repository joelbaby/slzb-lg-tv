# SLZB LG TV

An MIT-licensed LG webOS TV app being developed for SMLIGHT SLZB-OS coordinators.

**Status: development — not yet an installable or validated app.**

The required setup experience is **Pair in the app → Yes on the TV**. Version 1 will support one configurable TV with Pair, On, Off, and Forget, without Home Assistant or an ongoing helper service.

Pairing transport on current firmware is being investigated. A previous controlled experiment demonstrated direct power-off with an already-provisioned key, but this is not proof of the required in-app pairing flow.

See [the v1 specification](docs/specs/v1.md). Work and verification will be tracked in GitHub Issues and pull requests. No user credentials or private device captures belong in this repository.

This is an independent project, not affiliated with LG or SMLIGHT.
